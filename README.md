Terraform PowerShell Användare Automation

Målet med detta projekt är att enkelt kunna skapa flera användare samtidigt på miljön.

Verktygen som används för att uppnå dessa krav är PowerShell och Terraform, i form av 3 filer med hjälp av en JSON fil.
